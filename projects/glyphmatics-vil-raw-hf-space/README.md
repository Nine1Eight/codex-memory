# GlyphMatics VIL-RAW Encoder

Browser-based GlyphMatics encoder for code, files, folders, model blobs, GGUFs, OS images, and raw visual artifact restoration.

Core glyphstrings:

- `pgvayh` = install GlyphMatics core
- `pPvhz` = pack full runtime into `.gma.json`
- `pAvhz` = activate pack in isolated restore space
- `pLvhz` = append lineage block
- `pVvhz` = encode pack into raw visual memory image

Security rule:

G6 Signal is not G15 Key. Observation is not authorization. No G14 Lock without verification.
