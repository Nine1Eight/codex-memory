## What changed
- Hardened the API upload path with size, type, and empty-body validation.
- Made `/setup/status` tenant-aware and kept bootstrap messaging aligned with config.
- Added bootstrap persistence, analysis, receipt, and frontend deployment scaffolding.
- Removed stale hardcoded bootstrap thresholds from the static frontends.
- Added Cloudflare Worker, GitHub Pages, and Hugging Face deployment scaffolding.

## Why
- The repo was already enforcing bootstrap state and receipt generation, but the upload path and static surfaces still had production risks and stale placeholders.
- This update makes the current implementation safer to run and closer to deployable shape.

## Impact
- Rejects malformed or oversized uploads before analysis starts.
- Bootstrap status now respects the caller tenant.
- Frontends display the actual configured bootstrap threshold instead of a stale constant.
