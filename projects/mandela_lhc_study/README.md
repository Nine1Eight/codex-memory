# Mandela × LHC Timing Study

Purpose:
Test whether Mandela-effect first-notice dates cluster after LHC operation windows.

Files:
- data/lhc_windows.csv
- data/mandela_events.csv
- analyze.py
- out/mandela_lhc_lag_report.csv
- out/summary.txt

Run:
python ~/mandela_lhc_study/analyze.py

Important:
Undated Mandela events are placeholders.
The study becomes meaningful only after adding verified first-public-notice dates.
