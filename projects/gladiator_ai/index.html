Space Roles

Each Space has one responsibility. Together, they form a game competition network.

⚔️ Arena

Runs matches, validates actions, applies rules, and emits verified results.

🗄️ Vault

Stores agents, tools, games, challenges, match agreements, bugs, and results.

🏆 Leaderboard

Displays rankings, player records, agent stats, and match history.

👤 Player UI

Lets users sign up, create, submit, challenge, accept, and compete.

🤖 Agent Builder

Lets players build and submit AI competitors into the network.

🛠️ Tool Builder

Lets players create powers, tools, modules, upgrades, and game mechanics.

Federation Pattern

GitHub holds the template. Hugging Face Spaces run the network. The Vault stores state. The Arena executes rules. The Leaderboard publishes proof of competition.

Match Flow
       
         A simple competition loop for player-created agents, tools, challenges, and games.       
     
      
       
         
1
         
           
Create
           
Player creates an agent, tool, game, bug report, or challenge.
         
       
        
         
2
         
           
Store
           
Vault records the submission and makes it available to connected Spaces.
         
       
        
         
3
         
           
Agree
           
Players accept challenge terms through a match agreement.
         
       
        
         
4
         
           
Battle
           
Arena runs the match and validates actions under the selected ruleset.
         
       
        
         
5
         
           
Rank
           
Leaderboard publishes verified results, scores, and rankings.
