# Defendable IP Invention Record

This repository packages a technical invention record for patent-counsel development. It is not a filed patent application, legal opinion, freedom-to-operate opinion, or patentability determination.

## Included Deliverable

The staged record covers:

- Full system and process architecture
- Candidate novelty center
- Ownership and disclosure chain
- Biological and chemical boundaries
- Binder and cartridge architecture
- Independent system, method, and cartridge concepts
- Dependent fallback positions
- Prior-art pressure map
- Evidence-to-claim matrix
- Safety and containment barriers
- Patent-versus-trade-secret strategy
- Source record and USPTO defensibility standards

## Repository Layout

- `docs/technical-invention-record.md`: Primary textual invention record
- `docs/repository-notes.md`: Packaging notes and intended use
- `.gitignore`: Basic repository hygiene

## Handling Notes

This material should be treated as a confidential invention-development package unless and until counsel directs otherwise. Public publication can affect patent rights, trade-secret posture, and filing strategy.
